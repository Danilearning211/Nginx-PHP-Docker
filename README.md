# Nginx-PHP-Docker
Simple project to run PHP with Nginx using Docker.

* Nginx listens on port 80
* PHP requests are handled by PHP-FPM
* Docker is used to run the services

## Run

```bash
docker compose up -d --build
```
## Features

- [x] Nginx container
- [ ] PHP-FPM container
- [ ] Nginx PHP configuration
- [ ] Docker networking
- [ ] Test PHP page
